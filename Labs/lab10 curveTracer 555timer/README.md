*BJT Curve Tracer - lab 1 555 Timer*

This is the first in a series of laboratories aimed at building a BJT curve tracer.  This curve tracer
is based on the YouTuber w2aew video 
[#232: More Circuit Fun: Simple transistor curve tracer using Stairstep generator circuit](https://www.youtube.com/watch?v=ZOLLoa2fH24)

The hardware for this series of labs is located in this repo and the instructions are available in
[Lab01](here).
